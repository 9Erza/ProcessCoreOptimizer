# Process Core Optimizer v2.0.0

A major update focused on safer process optimization, advanced automation, a refined Windows experience, and improved reliability.

### Highlights

- Process Explorer 2.0 — grouped processes and individual instances.
- Profile Studio — improved profile creation and management.
- Smart Rules — process launch and foreground automation.
- EcoQoS — optional Windows efficiency controls.
- Live Insights — lightweight CPU and memory history.
- Reliability — safer process identity checks, restore, startup, and factory reset.
- Interface — refined navigation, developer hub, and Polish/English localization.

### Installation

Download **ProcessCoreOptimizer_Setup_2.0.0.exe** from Assets.

Windows 10/11 x64.

**Important:** Users of v1.3.0 should read the migration instructions before installing v2.0.0. This is not an in-place installer upgrade.
