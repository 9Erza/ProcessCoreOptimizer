# Process Core Optimizer v2.1.0

A redesigned, faster interface with full Polish translation, a reliable autostart, and fixes across the CPU affinity / CPU Sets engine.

## Highlights

- **Interface 2.1** - minimal dark design, icon sidebar, cards, toggle switches, and clearer page layouts.
- **Native Windows 11 window** - rounded corners, Snap Layouts, dark frame, and GPU composition instead of software rendering.
- **Autostart** - startup choices are registered with Windows, repaired automatically, and un-blocked when disabled in Task Manager; new Repair button.
- **CPU engine** - path-bound profiles for elevated / anti-cheat games, CPU Sets vs. stale affinity, drift re-apply, manual Apply no longer reverted.
- **Profiles** - fixes for hidden-profile deletion, EcoQoS-only profiles, priority-only profiles, and mask validation.
- **Localization** - full Polish translation of core presets, statuses, activity log, and window controls.

## Installation

Download **ProcessCoreOptimizer_Setup_2.1.0.exe** from the Assets section below.

**Requirements:** Windows 10/11 x64.

**Upgrading from v2.0.0:** run the installer - it upgrades the existing installation in place. Profiles and settings in `%APPDATA%\ProcessCoreOptimizer` are kept.
