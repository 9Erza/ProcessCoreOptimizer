# Process Core Optimizer v2.1.1

A maintenance update for v2.1.0 with an Erza Studio link and two reliability fixes.

## Highlights

- **Erza Studio** - "Made by Erza Studio" in Settings > About and an erza.studio link in the Developer Hub.
- **Reliability** - starting PCO a second time no longer crashes on a locked log file.
- **Window rendering** - areas not yet repainted show the app background instead of black; smoother opening from the tray.

## Installation

Download **ProcessCoreOptimizer_Setup_2.1.1.exe** from the Assets section below.

**Requirements:** Windows 10/11 x64.

**Upgrading from v2.0.x or v2.1.0:** run the installer - it upgrades the existing installation in place. Profiles and settings in `%APPDATA%\ProcessCoreOptimizer` are kept.
